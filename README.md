## 🛠 Tecnologia & Arquitetura

O site foi construído seguindo a filosofia **JAMstack** (JavaScript, APIs, Markup), focado em velocidade de carregamento e facilidade de deploy.

* **HTML5 Semântico:** Estrutura otimizada para SEO e Acessibilidade.
* **Tailwind CSS (CDN):** Estilização utilitária para desenvolvimento rápido e design system consistente (Glassmorphism).
* **JavaScript (Vanilla):** Scripts leves para animações de scroll (`IntersectionObserver`) e efeitos 3D nos cartões, sem dependência de frameworks pesados como React/Vue.
* **Hospedagem:** GitHub Pages (Deploy automático via Git).
